# aws-dict-sam

Back end of dictionary program. Enter a string like "m.c.i.e" to get words that fit the pattern - like "machine". Or select Anagram to find anagrams of a set of letters, Pangram to find pangrams, or Regex to match words against an arbitrary regular expression (e.g. "^re.*ing$"). Try it out at https://dict.ramakocherlakota.net/index.html

Front end code is in my aws-dict repo
